TabPaladin — design mockups

Non-shipping. Nothing here is wired into manifest.json, the extension, or the PWA. Both files reuse the existing design tokens and class names from src/sidepanel/sidepanel.css and pwa/app.css.

🖥️ PC — fullscreen extension pages Home with DuckDuckGo search, quick-action tiles, dashboard; two-pane notes reader; workflows (expanded + loading skeletons); organizer source picker; empty/first-run states. 📱 PWA — phone (390px) Home without search bar (quick actions, recent notes, folders), notes list with notebooks, black note reading page with task checkboxes, inbox sheet, loading/empty states.

Direction: drop the side-panel layout on PC in favor of full screens with a top nav bar; the PWA keeps its app-shell topbar. Shared components (.row, .action-tile, .card, skeletons) give both clients one visual language inside the existing palette.
