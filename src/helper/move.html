Move TabPaladin into your web app

TabPaladin now runs in your server's web app. This page hands over what this browser kept for it. Nothing here is deleted, and every copy arrives in the web app set aside first, never over work you have there.

Looking at what this browser holds…

1. Keep a backup file

One file with everything this browser's TabPaladin holds. Sign-in sessions and keys are left out. Keep it until you have checked the web app.

2. Your server

The TabPaladin web app at this address will be able to see the addresses and titles of your open tabs and to open and close tabs. The server operator can see what the web app receives. Nothing is sent anywhere else.

3. What moves

Kept in this browser

Copies made for another server never leave this browser. Download them here, or connect that server and move again.

4. Move

Opens your web app. Click Bring in there within ten minutes. Sign in there if it asks: your password and session never pass through this extension.
